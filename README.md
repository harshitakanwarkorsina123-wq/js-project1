#  Simon Game

A fun memory-based game built using **HTML, CSS, and JavaScript**.

### Features
- Interactive color buttons.
- Increasing difficulty levels.
- Score tracking.
- Simple and user-friendly design.

### How to Play
Remember the color sequence and repeat it correctly to reach the next level.

HTML | CSS | JavaScript
